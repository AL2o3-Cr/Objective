# Язык Objective полностью состоит из объектов.  

расширения файлов:
* .oj (ObJect)
* .uj (Universal objJect)
* .ej (Executable obJect)
* .pj (Point obJect)
* .ojs (ObJective Script)

## Родители и потомки  

Это система подбная наследованию, но она также работает как композиция.  
Родитель - обьект используемый как шаблон для создания потомка. 
В `int num` *int* - родитель, *num* - потомок. Но здесь, num не класса int, а является потомком, что имеет огромное значение в не-pj обьектах.

## uj, ej и pj

oj - изначальный обьект, из каторого рождаются главная троица.  
uj - структурирует программу, содержит в себе другие обьекты.  
ej - содержит исполняемый код, а также временые переменые типа pj и uj.  
pj - содержит данные, его структура: {name;data;type}

## Адресация

всегда можно обратиться к `ga`(global address).  
`ga:0` - прямое обращение к языку.  
`ga:1` - главный файл текущего исполнения.  
`ga:2` - общий импорт.  
`ga:3` ~ `ga:255` - иные файлы испонения не относящиеся к импорту. подлежит настройке. по умолчанию в `ga:5` лежит система.  
Пример - `ga:1.1` является заголовком исполняемого файла.  
Ещё есть `la`(local address).  
`sga`/`sla`(string global/local address) - текстовое представление.



## Встроенное :
### Типы :
* dict - содержит до 250 именованых обьектов, потомок uj
* arr - индексированый набор обьектов, потомок uj
* bit - один бит
* byte - один байт
* str - набор байтов специалезированый под запись текста
* num - набор байтов для записи любого числа, расширается по необходимости
* file - обьекты доступа к файловой системе, т. е. I/O
* ej - обьект содеражащий испоняемый код
* code("async" или "threads") - обьект содержащий код, исполняемый не последовательно или многопоточно

### Функиции

* ifs(bit$cond, oj$true,\ oj$false);  
* while(bit$cond, oj$true,\ oj$finally);  
* foreach(uj$code, num || uj,\ uj$finally);  
* switch(uj$var, dict$answers,\ uj$false);
