# Язык UniJect

Программа на *UniJect* полностью состоит из объектов.  
`UJ` это изначальный обьект.   
Выполняемая программа то же является обектом.

Из любого объекта можно обратиться к `ga`(global address).  
`ga0` - прямое обращение к языку.  
`ga1` - главный файл текущего исполнения.  
`ga2` - общий импорт.  
`ga3` ~ `ga255` - иные файлы испонения не относящиеся к импорту. подлежит настройке. по умолчанию в `ga5` лежит система.

## Встроенное :
### Классы :
* `uj`
* `arr` - индексированый набор конечных данных
* `bit`
* `byte`
* `file`
### Функиции :
* `ifs(bit$cond, uj$true,\ uj$false);`
* `while(bit$cond, uj$true,\ uj$finally);`
* `foreach(uj$code, arr || byte || uj,\ uj$finally);`
* `switch(uj$var, uj$answers,\ uj$false);`
